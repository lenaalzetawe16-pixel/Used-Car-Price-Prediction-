# 🚗 نظام توقع أسعار السيارات المستعملة

نموذج ذكاء اصطناعي ذكي مصمم لتقدير القيمة السوقية للسيارات المستعملة بناءً على مواصفاتها وحالتها.

## 🎯 لمحة عن المشروع
بصفتي مهندسة ميكاترونكس، قمت بتطبيق تقنيات تحليل البيانات لحل مشكلة تسعير حقيقية. الهدف كان بناء نموذج قادر على توقع أسعار السيارات بدقة عالية، مما يساعد البائعين والمشترين على اتخاذ قرارات مبنية على بيانات دقيقة.

## 🛠️ الأدوات والتقنيات المستخدمة
- **لغة البرمجة:** Python (مكتبات Pandas, NumPy).
- **الرسم البياني:** Matplotlib, Seaborn.
- **تعلم الآلة (Machine Learning):** Scikit-Learn (خوارزمية Random Forest Regressor).
- **هندسة الخصائص (Feature Engineering):** التحويل اللوغاريتمي، والترميز الأحادي (One-Hot Encoding).

## 📊 النتائج الرئيسية
- **النموذج المستخدم:** الغابة العشوائية (Random Forest).
- **الدقة المحققة:** **92.42%** (R2 Score).
- **أهم الاكتشافات:** تبين أن "الشركة المصنعة" (Make) و "عمر السيارة" (Car Age) هما العاملان الأكثر تأثيراً في تحديد السعر، يليهما حجم المحرك.
